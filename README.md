# Double Subs

Netflix를 보면서 일본어·영어를 공부하는 이중 자막 Chrome 확장 프로그램입니다. 무료이고, 광고와 데이터 수집이 없습니다.

- 원문 자막과 한국어 자막을 영상 아래에 함께 보여 줍니다.
- 한국어 자막이 없는 작품은 AI가 회차 흐름을 보며 한국어로 번역합니다.
- 단어에 마우스를 올리면 뜻과 읽는 법, 누르면 이 장면에서의 뜻과 예문('자세히')이 나옵니다.
- 오른쪽 대본, 문장 반복, 단어·문장 저장.

개인정보 처리방침: [PRIVACY.md](PRIVACY.md)

## 설치

1. Chrome 웹스토어 링크(공유받은 주소)를 열고 **Chrome에 추가**를 누릅니다.
2. 오른쪽 위 퍼즐 모양 아이콘에서 Double Subs를 고정해 두면 편합니다.

## AI 연결 (둘 중 하나)

AI를 연결하지 않아도, 일본어·한국어 공식 자막이 모두 있는 작품에서는 이중 자막과 대본이 동작합니다. AI 번역과 단어 뜻에는 연결이 필요합니다.

**Gemini API 키**
1. Google AI Studio에서 API 키를 만듭니다 (또는 받은 키를 씁니다).
2. 확장 아이콘 → **설정** → **Gemini API 키**에 붙여 넣고 **저장**.
3. **연결 확인**을 눌러 `연결됨`이 뜨면 끝입니다.

키는 내 브라우저에만 저장되고, 개발자에게 전송되지 않습니다.

**ChatGPT 구독 (Windows)**
ChatGPT 구독(Plus 등)으로 번역하려면 PC에 작은 도우미를 설치합니다. Codex 앱에 붙여 넣을 설치 안내는 곧 이곳에 추가됩니다.

## 쓰는 법

Netflix에서 작품을 재생하면 자막 칸과 오른쪽 대본이 자동으로 나타납니다.

| 키 | 동작 |
|---|---|
| `A` / `D` | 이전 / 다음 문장 |
| `S` | 지금 문장 처음부터 다시 |
| `Space` | 재생 / 일시 정지 |
| `R` | 지금 문장 저장 |
| `F` | 후리가나 켜기 / 끄기 |
| `T` | 오른쪽 대본 켜기 / 끄기 |
| `?` | 단축키 전체 보기 |

비상업적 개인 사용을 위한 프로그램입니다.
